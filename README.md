# Bootleggers Revived

Public download repository for finished Bootleggers Revived images.

Each release may include:

- Android system image
- Compressed image
- SHA-256 checksums
- Compatibility report and build provenance

The source code and build automation are kept privately in [BootleggersRevivedSource](https://github.com/realheckerrr-bit/BootleggersRevivedSource).
